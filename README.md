# File Upload & Download Backend

This project allows users to upload, list, and download files with authentication support.
---

# Setup Instructions

1. **Clone the repository**

  - git clone <your-repo-url>
  -  cd <your-repo-folder>


2. **Install dependencies**

  - npm install


3. **Environment Variables**

  - Rename the env file to .env:


  - Open .env and fill in the required environment variables.


# Make sure all keys are set properly for your backend to run.

4. **Run the application**

  - node index.js


The server should start on the port defined in your .env (default: 5000).

Visit http://localhost:5000 to access the application.
